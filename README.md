## 🚀 Что нового в версии 3.0.22102026 (Major Release)

Релиз **3.0.22102026** — это фундаментальный этап развития JARVIS GeoBot, сочетающий переход на дизайн-систему Liquid Glass, сверхвысокую детализацию медиаконтента, многоуровневую систему модерации и комплексный правовой щит:

1. **🎨 Дизайн-система Liquid Glass (iOS/macOS Glassmorphism)**:
   - Полный переход на модульные токены (`tokens.css`, `typography.css`, `liquid_glass.css`).
   - Полупрозрачные подложки с эффектом матового стекла (`backdrop-filter: blur`), скругления squircles, динамическая адаптация к тёмной и светлой темам Telegram и тактильный виброотклик (Haptic Feedback).

2. **🏰 4K Ultra HD визуализация и детальный просмотр**:
   - Новая заставка в разрешении **4K Ultra HD** (`frontend/mir_castle.webp`, 3840×2142, ~8.23 Мп) с мгновенным сбросом кеша клиентов.
   - Углублённый просмотр карточек в Retina/HD-качестве (1200×800 WebP и оригиналы Wikimedia Commons) с аппаратным сглаживанием контраста.

3. **🛡️ Фильтрация контента и система оперативной модерации**:
   - Автоматическая фильтрация метаданных Wikimedia с защитой от обхода (NFKC-нормализация и удаление zero-width символов).
   - Запрет нежелательного контента: протестная символика (БЧБ), конфликтная и военная символика (Z, V, СВО, вооружённые формирования, лозунги), нацизм, экстремизм, насилие и 18+/NSFW.
   - **Инструменты пользователя и модератора в 1 клик**: кнопки «Пожаловаться» (🚩) и «Удалить» (🗑️) прямо в правом углу крупного фото с векторными SVG-иконками, моментальной блокировкой в БД и очисткой дискового кеша.

4. **⚖️ Комплексный правовой щит ([`LEGAL.MD`](LEGAL.MD))**:
   - Встроенный визуализатор правовой информации с собственным Markdown-парсером (без сырых звёздочек `**`, заголовки, списки, цитаты, разделы).
   - Фиксация статуса информационного посредника (Notice & Takedown), соблюдение открытых лицензий OpenStreetMap (ODbL) и Wikimedia Commons (CC BY-SA), соответствие Закону РБ № 99-З «О защите персональных данных».

5. **⚡ Надёжность и 100% покрытие автотестами**:
   - 108 юнит- и интеграционных тестов backend (`pytest`) + 29 сквозных тестов правового модуля.

## ✨ Возможности для путешественников

### 🏰 Умный каталог достопримечательностей
- **Историческое наследие**: Замки, дворцы, оборонительные церкви, ратуши, храмы, монастыри и заповедники Беларуси.
- **Интеллектуальный ранжирующий поиск**: Приоритет отдаётся ключевым историко-культурным ценностям первой величины.
- **Тематические фильтры**: Замки, Архитектура, Природа, Музеи, Храмы, Памятники, Парки.
- **Радиусный поиск (+25 км)**: Кнопка «Исследовать окрестности» находит скрытые усадьбы и природные объекты в радиусе 25 км от выбранного города.

### 🧭 Алгоритмический оптимизатор маршрутов (TSP 2-Opt)
- Выберите от 2 до 30 интересных мест в любом порядке.
- Алгоритм решения задачи коммивояжёра (Nearest Neighbor + 2-Opt) выстраивает наилучшую последовательность объезда, минимизируя время в пути.
- Расчёт реального километража по дорожной сетке через OSRM.
- **Переход в Google Maps в 1 клик**: готовая навигация «от точки к точке» прямо в вашем смартфоне.

### 🌤️ Интерактивная метеостанция
- Текущая температура, влажность, атмосферное давление и скорость ветра.
- Почасовой график вероятности осадков и облачности на 24 часа.
- Долгосрочный прогноз на 3 дня и время восхода/заката солнца.

### ❤️ Избранное и мультиязычность
- Сохранение любимых мест в один тап с привязкой к вашему Telegram ID.
- Полная двуязычная локализация: Русский (RU) и Белорусский (BY).

## 🤖 Команды Telegram-бота

### Для пользователей
- `/start` — Приветствие, регистрация сессии и кнопка запуска WebApp.
- `/help` — Руководство по навигации, составлению маршрутов и прогнозу погоды.
- `/support` — Правовая информация, источники данных и контакты поддержки.

### Для администраторов (3-уровневый RBAC: USER < ADMIN < SUPERADMIN)
- `/ban <user_id | @username> [причина]` — Ограничение доступа к сервису.
- `/unban <user_id | @username>` — Восстановление доступа.
- `/user <user_id | @username>` — Просмотр профиля, роли и баланса токенов.
- `/broadcast <сообщение>` — Рассылка важного оповещения всем активным пользователям.
- `/promote <user_id>` / `/demote <user_id>` — Управление администраторами (только Superadmin).
- `/maintenance [on|off]` — Режим технического обслуживания (только Superadmin).

## ⚡ Быстрый старт для операторов

### Системные требования
- **Python 3.10+**
- **PostgreSQL 14+**
- **Redis 6+**
- **Telegram Bot Token** (от [@BotFather](https://t.me/botfather))

### 1. Клонирование и установка окружения

```bash
git clone https://github.com/kirwjb/Jarvis-geobot.git
cd Jarvis-geobot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка переменных окружения

Скопируйте шаблон `.env.example` в `.env`:

```bash
cp .env.example .env
```

Заполните ваши параметры доступа:

```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
SUPER_ADMINS=ваш_telegram_id

DB_USER=postgres
DB_PASSWORD=ваш_пароль
DB_HOST=localhost
DB_PORT=5432
DB_NAME=jarvis_db

REDIS_HOST=localhost
REDIS_PORT=6379
```

### 3. Миграции и запуск

Примените миграции базы данных:

```bash
alembic upgrade head
```

Проверьте статус готовности сервисов:

```bash
./jarvis status
```

Запустите совмещённый сервер FastAPI + Telegram Bot:

```bash
./jarvis -r
```

Приложение доступно по адресу `http://localhost:8000`.

### Запуск тестов

```bash
./jarvis test
# или напрямую: pytest src/tests -v
```
